# Game textures that hold PlayStation button art (BCUS98158), for
# src/gt5p_glyphs.cpp. One texture per line:
#   <hash> <w>x<h> <button>@<x>,<y>,<w>,<h> ...
# <hash> is the backend's FNV-1a 64 of the texture's bytes, as
# RSX_TEX_REPL_DUMP=<dir> names its dumps. Each cell holds one button; its
# pixels (a flood from the cell's centre) are cleared and the style's art is
# drawn where they were (less inset=N texels each side, which keeps the gaps
# between buttons), or in the box after a "/" when one is given.
# outline:<button>@<box> marks the game's red highlight ring for that button
# of the diagram (<box>: the button in the diagram, "/" box as for its cell).
# The ring is redrawn around the new art, ring=N texels wide.
# Buttons: cross circle square triangle l1 r1 l2 r2 l3
# r3 start select up down left right, and label (a printed name, cleared).
